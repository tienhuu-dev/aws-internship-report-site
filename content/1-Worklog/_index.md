In the **Worklog** section, I summarize my learning and practical experience during the 12-week internship in the **First Cloud AI Journey** program as a **Cloud Infrastructure Engineer** for the **CloudDoc** project. Each week follows the same structure, including weekly objectives, tasks carried out, and achievements, in accordance with the internship report requirements.

The journey is organized from learning **AWS** fundamentals, completing infrastructure labs, and participating in workshops and office activities, to deploying, configuring, and managing **AWS Cloud** infrastructure for the **CloudDoc** system. My responsibilities included setting up AWS resources, configuring networking and security, managing access permissions, monitoring the system, optimizing costs, and supporting application deployment. The internship progress is divided into the following weeks:

**Week 1:** [Getting familiar with AWS and basic AWS services](1.1-week1/)

**Week 2:** [Learning Compute and Storage with EC2, Auto Scaling, Lightsail, S3, EBS, EFS, Storage Gateway, and Snow Family](1.2-week2/)

**Week 3:** [Learning CloudFront, advanced Networking, ALB, RDS, DynamoDB, and ElastiCache](1.3-week3/)

**Week 4:** [Learning Lambda, API Gateway, SQS, SNS, CloudWatch, and implementing a Serverless Lab](1.4-week4/)

**Week 5:** [Learning Secrets Manager, KMS, CloudFormation, CodeBuild, CodePipeline, and CI/CD](1.5-week5/)

**Week 6:** [Learning AWS Security and Containerization with Security Hub, GuardDuty, WAF, Cognito, ECR, ECS, and Fargate](1.6-week6/)

**Week 7:** [Learning Route 53, HTTPS, monitoring, governance, event-driven serverless, backup, cost optimization, and the Well-Architected Framework](1.7-week7/)

**Week 8:** [Learning AI/ML with Amazon Bedrock, SageMaker AI, Rekognition, Textract, and Comprehend; improving the architecture diagram](1.8-week8/)

**Week 9:** [Designing a three-tier cloud architecture and deploying networking, NAT Instance, and S3 infrastructure for CloudDoc](1.9-week9/)

**Week 10:** [Deploying RDS PostgreSQL, EC2 Application Servers, ALB, SQS, DLQ, and S3 Event Notification](1.10-week10/)

**Week 11:** [Completing CloudFront, CloudWatch, SNS, S3 Lifecycle, and overall cloud infrastructure integration testing](1.11-week11/)

**Week 12:** [Testing, reviewing security and monitoring, optimizing costs, summarizing the project, and finalizing the internship report](1.12-week12/)
