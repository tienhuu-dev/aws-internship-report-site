# Summary Report: “FCAJ Community Day”

### Event Objectives

- Learn about **Generative AI** and how to build effective AI applications
- Explore AWS services for data analysis and workflow automation
- Understand the role of **Amazon CloudFront** in improving performance, security, and cost efficiency
- Learn about **LLMs**, **Multi-Agent Systems**, and their practical deployment challenges

### Key Highlights

#### Context Is Everything: Making AI Actually Work for You

- Understand why AI performs poorly without sufficient **context**
- Learn about the evolution from **prompts** to **memory**
- Explore the **Second AI Brain** concept
- Learn how students can start building AI-powered products

#### Friendly AI Assistant with Amazon Quick

- **Quick Chat Agent**: Explore data and analyze insights
- **Quick Flows**: Create workflows using natural language without coding
- **Quick Spaces**: Build collaborative spaces for knowledge sharing
- **Quick Sight**: Create dashboards and reports from raw data

#### From Edge to Origin: CloudFront as Your Foundation

- Use **Amazon CloudFront** for different types of workloads
- Optimize content delivery costs
- Improve security capabilities
- Enhance system reliability and performance

#### 36 hrs with LotusHacks – Building UTMorpho from Idea to Reality

- Motivation for joining LotusHacks
- Idea generation and product development process
- Problem definition and product direction
- Product development within 36 hours
- Challenges, failures, and lessons learned

#### Non-Determinism of “Deterministic” LLM Settings

- Understand how LLMs select the next token
- Examine the assumption that `Temperature = 0` always guarantees deterministic results
- Identify inference factors that may cause different outputs
- Learn about practical impacts and mitigation strategies

#### Enterprise-Grade Multi-Agent System

- Understand the mismatch between startup data and banking data
- Learn when to use and when not to use a **Single Agent**
- Explore the **Multi-Agent System** paradigm
- Review the **Virtual Credit Committee** blueprint
- Understand **Guardrails**, **Compliance**, and implementation roadmaps
- Evaluate **Operational ROI**

### Key Takeaways

#### Generative AI Knowledge

- Understand the importance of **context** in improving AI output quality
- Distinguish between **prompts**, **memory**, and other context-providing methods
- Recognize non-deterministic behavior during LLM inference

#### AWS Architecture and Services

- Understand how **Amazon CloudFront** improves performance, security, and reliability
- Learn how Amazon Quick supports data analysis and workflow automation
- Recognize guardrail and compliance requirements for enterprise AI systems

#### Product Development

- Understand how to turn an idea into a product within a limited timeframe
- Recognize the importance of defining the right problem and product scope
- Learn from challenges, failures, and turning points during development

### Applying to Work

- Provide sufficient **context** when using AI tools during development
- Use AI to support document analysis, data processing, and suitable workflow automation
- Consider performance, security, and cost when designing content delivery with CloudFront
- Include **guardrails** and **compliance** requirements in AI features
- Evaluate LLM output stability before using it in business processes
